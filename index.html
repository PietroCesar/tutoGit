GIT

O Git é um sistema de controle de versão distribuído, gratuito e de código aberto, usado para rastrear e gerenciar alterações em arquivos e códigos de programação. Criado em 2005 por Linus Torvalds (o criador do Linux), ele permite que você salve diferentes versões do seu projeto, volte no tempo caso algo dê errado e trabalhe em equipe sem que o trabalho de uma pessoa sobrescreva o da outra.

Resumo dos comandos
Comandos Função
git init Cria um novo repositório Git na pasta atual.
git status Mostra o estado atual dos arquivos e alterações
git add Adiciona arquivos para serem incluídos no próximo commit.
git commit Salva as alterações no histórico do projeto.
git remote -v serve para ver os repositórios remotos conectados ao seu projeto, normalmente o repositório do GitHub.
git add Adiciona arquivos para serem incluídos no próximo commit.
git remote add origins Esse comando serve para conectar seu projeto local a um repositório remoto, geralmente no GitHub.
git push origin main Adiciona arquivos para serem incluídos no próximo commit.
